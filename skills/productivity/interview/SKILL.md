---
name: interview
description: Interview the user in question batches about a plan or design. Use when the user wants to stress-test a plan before building.
disable-model-invocation: true
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions. For each question, provide your recommended answer.

Ask questions in batches of up to 8. Number the questions so I can answer them by number. Only batch questions that are independent of each other; if a question's framing depends on the answer to another, hold it for a later batch.

If I answer only some questions in a batch, treat the recommended answers as accepted for the ones I skipped, but confirm that assumption in your next message.

If a question can be answered by exploring the codebase, explore the codebase instead.
