# Documentation

## Overview

Use this skill to create or update durable project documentation that captures intent, not just implementation.

For now, this skill only defines ADR guidance. When the task involves an architectural decision record, read [adr.md](adr.md) before writing or modifying the ADR.

## Current Scope

- **ADRs**: Use [adr.md](adr.md) for when to create one, where to place it, how to number it, and what format to use.

Do not invent additional documentation workflows under this skill until they are added here or in a directly linked reference file.
